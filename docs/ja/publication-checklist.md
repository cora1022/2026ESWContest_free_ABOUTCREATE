# 公開前チェックリスト

[English](../publication-checklist.md) | [한국어](../ko/publication-checklist.md) | [日本語](publication-checklist.md)

このチェックリストは、ソース、Git履歴、バックアップの圧縮ファイル、制作写真、音声、デモ動画を公開する前に確認する項目です。

## APIキーとGit履歴

- [ ] `.env`、実際のAPIキー、パスワード、秘密鍵、サービスアカウントファイルが追跡されていない。
- [ ] 現在のファイルだけでなく、すべてのブランチ、タグ、コミットを検査した。
- [ ] zip、pyc、ログ、エディターのバックアップ、ビルド成果物も検査した。
- [ ] 漏えいしたキーは、リポジトリから削除する前にサービス側で失効させた。
- [ ] `.env.example` にはサンプル値だけが含まれている。

```bash
git status --ignored
git ls-files
git grep -n -I -E "AIza|API_KEY|secret|token|password|credential"
git log -p --all | rg -i "AIza|API_KEY|secret|token|password|BEGIN .*PRIVATE KEY"
```

検索結果をそのままIssueや文書に貼り付けないでください。値が見つかった場合は、キーの失効、履歴の整理、フォークとキャッシュへの露出範囲の順に確認します。

## 個人情報と撮影データ

- [ ] 実名、メールアドレス、電話番号、ローカルユーザーのパス、デバイス名を確認した。
- [ ] Wi-FiのSSIDとパスワード、内部IP、SSHとポートフォワーディングの情報が含まれていない。
- [ ] 写真、GIF、動画に顔、文書、学生証、伝票、ナンバープレートが映り込んだり、声が収録されたりしていない。
- [ ] EXIFと撮影位置のメタデータを確認した。
- [ ] 動画に映る人、または声が収録されている人から公開の同意を得た。
- [ ] YouTubeの公開範囲と、ログアウト状態でREADMEのリンクへアクセスできることを確認した。

## カメラ、音声、LLMの範囲

- [ ] カメラで撮影したJPEGと音声録音ファイルがリポジトリに残っていない。
- [ ] Geminiへ送信される可能性がある画像とテキストの範囲を説明した。
- [ ] gTTSとGoogle音声認識がネットワークを使用することを説明した。
- [ ] モデルの応答や認識結果が誤っている可能性を制限事項に記載した。

## 実装と文書の一致

- [ ] 現在のエントリーポイントが `python main_brain.py` であることを確認した。
- [ ] `test_case.py` はプラン確認専用であり、ハードウェア試験ではないことを記載した。
- [ ] Gemini JSONプラン → 許可リストディスパッチャー → `hardware.py` の流れを正確に説明した。
- [ ] GPIO、カメラ、マイク、超音波センサーの実装と実際のピンをコードに基づいて確認した。
- [ ] 25 cmでの前進ブロックと18 cmでの連続走行停止を区別した。
- [ ] センサーのタイムアウト、後方と側面のセンサー、物理的な緊急停止に関する制限を記載した。
- [ ] `2main_brain.py` を実行可能な現行コードとして紹介していない。
- [ ] 動画に示された機能と現在の公開コードが、同じ最終統合版に基づいていることを確認した。

## 実機の安全

- [ ] HC-SR04のECHOに5 Vから3.3 Vへの電圧変換を適用した。
- [ ] モーター用の独立電源、ドライバー、共通グラウンド、保護装置を確認した。
- [ ] 車輪を浮かせた状態で、方向、停止、距離インターロックを試験した。
- [ ] モーター電源をすぐに切断できる物理スイッチが手の届く位置にある。
- [ ] 人や障害物がない場所で低速試験を行った。

## リポジトリの最終確認

- [ ] cloneのURLが `cora1022/gemini-raspberry-pi-robot.git` に統一されている。
- [ ] READMEと `docs/` の相対リンクと画像が正しく表示される。
- [ ] Pythonファイルが構文検査を通過する。
- [ ] `git diff --check` と機密情報の検索を通過する。
- [ ] ライセンスと外部アセットの公開条件を確認した。
- [ ] 新しいフォルダーへ再度cloneし、インストール手順と文書の内容を再確認した。
