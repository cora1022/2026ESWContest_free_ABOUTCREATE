# ADR 0001. Raspberry Pi가 안전정지를 소유한다

- 상태: 승인
- 날짜: 2026-09-02

## 배경

브라우저, 인터넷 또는 VPS가 중단돼도 로봇 본체와 모터 전원은 계속 살아 있을 수 있습니다. 서버가 모터 정지 여부를 최종 판단하면 연결 단절 순간에 STOP을 전달할 수 없습니다.

## 결정

Raspberry Pi가 다음 안전 규칙을 직접 실행합니다.

- 주행 명령 만료시간 검사
- 짧은 원격 주행 lease와 watchdog
- VPS 연결 해제 시 즉시 모터 정지
- 전진 전 HC-SR04 거리 확인
- 센서 비활성, timeout과 오류 시 전진 차단
- 프로세스 종료 시 GPIO LOW와 cleanup

VPS는 명령을 인증하고 중계하지만 모터를 직접 제어하지 않습니다.

## 결과

네트워크 장애가 안전정지를 막지 않습니다. 대신 Pi에 서버와 일부 중복되는 명령 검증이 필요하고, 실제 안전 성능은 Pi 프로세스와 GPIO 회로가 정상 작동한다는 전제에 의존합니다. 하드웨어 emergency stop을 대체하지는 않습니다.
