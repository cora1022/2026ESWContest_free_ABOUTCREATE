# ADR 0003. 영상과 텔레메트리는 최신 값을 우선한다

- 상태: 승인
- 날짜: 2026-09-02

## 배경

네트워크 처리량보다 카메라 frame 생성 속도가 빠르면 전송 queue가 과거 frame으로 쌓입니다. 모든 frame을 순서대로 보내면 연결은 유지돼도 사용자는 오래된 장면을 보게 되고 STOP 결과가 영상 뒤에 대기할 수 있습니다.

## 결정

- 아직 전송하지 않은 영상 frame은 더 최신 frame으로 교체합니다.
- telemetry도 최신 snapshot 하나만 유지합니다.
- `command_result`와 `status`는 별도 우선 queue를 사용합니다.
- WebSocket send에 제한시간을 적용하고 초과 시 연결을 재수립합니다.
- JPEG는 Base64가 아닌 `RBT1` binary frame으로 Pi에서 VPS까지 전송합니다.

## 결과

혼잡할 때 일부 frame과 중간 telemetry는 의도적으로 유실되지만 화면 지연이 무한히 누적되지 않습니다. 이 정책은 감시 영상 보관보다 실시간 원격 조작에 적합합니다. 명령 결과와 안전 상태는 교체 대상이 아닙니다.
