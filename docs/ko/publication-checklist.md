# 공개 전 체크리스트

[English](../publication-checklist.md) | [한국어](publication-checklist.md) | [日本語](../ja/publication-checklist.md)

이 체크리스트는 소스, Git 기록, 백업 압축 파일, 제작 사진, 음성과 시연 영상을 공개하기 전에 확인할 항목입니다.

## API 키와 Git 기록

- [ ] `.env`, 실제 API 키, 비밀번호, 개인키, 서비스 계정 파일이 추적되지 않는다.
- [ ] 현재 파일뿐 아니라 모든 브랜치·태그·커밋을 검사했다.
- [ ] zip, pyc, 로그, 에디터 백업과 빌드 산출물도 검사했다.
- [ ] 노출된 키는 저장소에서 지우기 전에 서비스에서 먼저 폐기했다.
- [ ] `.env.example`에는 예시 값만 있다.

```bash
git status --ignored
git ls-files
git grep -n -I -E "AIza|API_KEY|secret|token|password|credential"
git log -p --all | rg -i "AIza|API_KEY|secret|token|password|BEGIN .*PRIVATE KEY"
```

검색 결과를 그대로 이슈나 문서에 붙여 넣지 않습니다. 값이 발견되면 키 폐기, 기록 정리, 포크·캐시 노출 범위를 차례로 확인합니다.

## 개인정보와 촬영 자료

- [ ] 실명, 이메일, 전화번호, 로컬 사용자 경로와 장치 이름을 확인했다.
- [ ] Wi-Fi SSID·비밀번호, 내부 IP, SSH·포트 포워딩 정보가 없다.
- [ ] 사진·GIF·영상에 얼굴, 목소리, 문서, 학생증, 송장, 번호판이 노출되지 않는다.
- [ ] EXIF와 촬영 위치 메타데이터를 확인했다.
- [ ] 영상에 등장하거나 목소리가 들리는 사람의 공개 동의를 확인했다.
- [ ] YouTube 공개 범위와 README 링크의 로그아웃 접근을 확인했다.

## 카메라·음성·LLM 범위

- [ ] 카메라가 촬영한 JPEG와 음성 녹음 파일이 저장소에 남지 않는다.
- [ ] Gemini에 전송될 수 있는 이미지와 텍스트의 범위를 설명했다.
- [ ] gTTS와 Google 음성 인식이 네트워크를 사용한다는 점을 설명했다.
- [ ] 모델 응답과 인식 결과가 틀릴 수 있음을 제한사항으로 남겼다.

## 구현과 문서 일치

- [ ] 현재 진입점이 `python main_brain.py`임을 확인했다.
- [ ] `test_case.py`는 계획 전용이며 하드웨어 시험이 아님을 적었다.
- [ ] Gemini JSON 계획 → 허용 목록 디스패처 → `hardware.py` 흐름을 정확히 설명했다.
- [ ] GPIO, 카메라, 마이크, 초음파 구현과 실제 핀을 코드 기준으로 확인했다.
- [ ] 전진 차단 25cm와 연속 주행 정지 18cm를 구분했다.
- [ ] 센서 타임아웃, 후방·측면 센서, 물리 긴급 정지의 한계를 적었다.
- [ ] `2main_brain.py`를 실행 가능한 현재 코드로 소개하지 않았다.
- [ ] 영상의 기능과 현재 공개 코드가 같은 최종 통합본에 기반함을 확인했다.

## 실물 안전

- [ ] HC-SR04 ECHO에 5V→3.3V 전압 처리를 적용했다.
- [ ] 모터 별도 전원, 드라이버, 공통 접지와 보호 장치를 확인했다.
- [ ] 바퀴를 띄운 상태에서 방향·정지·거리 인터록을 시험했다.
- [ ] 모터 전원을 즉시 끌 수 있는 물리 스위치가 손에 닿는다.
- [ ] 사람과 장애물이 없는 공간에서 낮은 속도로 시험했다.

## 저장소 최종 점검

- [ ] clone 주소가 `cora1022/gemini-raspberry-pi-robot.git`로 통일되어 있다.
- [ ] README와 `docs/`의 상대 링크와 이미지가 정상이다.
- [ ] Python 파일이 구문 검사를 통과한다.
- [ ] `git diff --check`와 비밀정보 검색을 통과한다.
- [ ] 라이선스와 외부 에셋의 공개 조건을 확인했다.
- [ ] 새 폴더에 다시 clone하여 설치·문서 절차를 재검토했다.
