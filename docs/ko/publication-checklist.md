# 공개 전 체크리스트

[English](../publication-checklist.md) | [한국어](publication-checklist.md)

이 체크리스트는 저장소, 커밋 기록, 제작 사진, 음성, 시연 영상과 외부 링크를 공개하기 전에 확인할 항목을 정리합니다. 현재 파일에서 값을 지우는 것만으로 과거 Git 기록이나 이미 공개된 키가 안전해지는 것은 아닙니다.

## API 키와 비밀정보 검사

- [ ] 실제 `GOOGLE_API_KEY`가 `.env.example`이나 문서에 들어 있지 않다.
- [ ] `.env`와 `.env.*`가 무시되고 `.env.example`만 추적된다.
- [ ] Google API 키뿐 아니라 GitHub 토큰, 클라우드 키, 개인키, 비밀번호와 서비스 계정 파일을 검사했다.
- [ ] 노출된 키가 있었다면 먼저 해당 서비스에서 폐기하고 새 키를 발급했다.
- [ ] 현재 작업 트리와 모든 브랜치·태그의 Git 기록을 검사했다.

현재 파일 확인 예시:

```bash
git status --ignored
git ls-files
git grep -n -I -E "GOOGLE_API_KEY|AIza|secret|token|password|credential"
```

Git 기록 확인 예시:

```bash
git log --all --oneline --decorate
git log -p --all | rg -i "GOOGLE_API_KEY|AIza|secret|token|password|credential|BEGIN .*PRIVATE KEY"
git log --all --name-only --pretty=format: | rg -i "\.env|\.pem|\.key|credential|service.?account"
```

검색어는 사용하는 서비스에 맞게 추가합니다. 비밀정보를 발견하면 단순히 최신 파일에서 삭제하지 말고 키를 폐기한 뒤 Git 기록 정리 필요성을 판단합니다.

## 개인정보 검사

- [ ] README, 코드 주석, 로그 예시에 실명·이메일·전화번호가 불필요하게 포함되지 않았다.
- [ ] 로컬 사용자명과 홈 디렉터리 경로가 로그나 스크린샷에 노출되지 않았다.
- [ ] Raspberry Pi 호스트명, 장치 일련번호, 내부 IP, MAC 주소와 SSH 설정을 확인했다.
- [ ] 터미널 기록이나 오류 메시지에 개인 경로와 토큰이 보이지 않는다.

## 실제 위치와 무선 네트워크 정보

- [ ] Wi-Fi SSID와 비밀번호가 코드, 설정 파일, 터미널 화면에 없다.
- [ ] 공유기 관리 주소, 고정 IP, 포트 포워딩과 원격 접속 정보가 노출되지 않았다.
- [ ] GPS 좌표, 집·학교·회사 주소, 창밖 풍경과 위치를 유추할 수 있는 표지판을 확인했다.
- [ ] 촬영 파일명이나 메타데이터에 위치 정보가 남아 있지 않다.

## 이미지와 촬영 자료

- [ ] 사진과 GIF의 EXIF 등 메타데이터를 확인했다.
- [ ] 모니터, 휴대전화, 문서, 택배 송장, 학생증·사원증, 차량 번호판이 보이지 않는다.
- [ ] 반사면이나 배경에 사람과 사적인 공간이 의도치 않게 찍히지 않았다.
- [ ] 카메라가 촬영한 원본 데이터 중 공개하면 안 되는 파일이 저장소에 없다.
- [ ] 제3자 이미지, 아이콘, 음악과 영상의 사용 권한을 확인했다.

## 음성과 시연 영상 공개 범위

- [ ] 영상에 등장하거나 목소리가 들리는 사람이 공개에 동의했다.
- [ ] 대화 속 이름, 주소, 계정, 학교·회사 정보와 개인 일정이 노출되지 않는다.
- [ ] YouTube 영상과 썸네일의 공개·일부 공개·비공개 설정이 의도와 일치한다.
- [ ] README에서 연결한 모든 영상 링크를 로그아웃 상태에서도 확인했다.
- [ ] 영상 속 실물 프로토타입 기능과 현재 공개 코드로 재현 가능한 기능을 구분해 설명했다.
- [ ] 카메라·센서·GPIO 코드가 없는데 구현되어 있다고 표현하지 않았다.
- [ ] 프롬프트의 안전 지시를 코드 수준 안전장치라고 표현하지 않았다.

## 저장소 최종 확인

- [ ] clone 주소가 `cora1022/gemini-raspberry-pi-robot.git`로 통일되어 있다.
- [ ] README와 `docs/`의 상대 링크와 이미지가 정상이다.
- [ ] `python test_case.py`가 현재 공개 코드의 실행 예제로 안내되어 있다.
- [ ] `python main_brain.py`와 `python 2main_brain.py`의 현재 한계가 설명되어 있다.
- [ ] 공개 코드가 실제 모터를 움직이지 않는다는 사실이 명확하다.
- [ ] 새로 추가한 파일과 삭제한 파일을 `git status`에서 확인했다.
- [ ] 커밋할 diff에 Python 구현 변경이 없는지 확인했다.
- [ ] 라이선스와 외부 에셋의 배포 조건을 확인했다.
- [ ] 가능하면 새 폴더에 다시 clone하여 문서와 설치 절차를 점검했다.

## 공개 후 대응

- 공개 후 비밀정보를 발견하면 저장소를 비공개로 바꾸는 것만으로 끝내지 않습니다.
- 노출된 키와 비밀번호를 즉시 폐기합니다.
- 필요한 경우 Git 기록과 릴리스·포크·캐시의 노출 범위를 확인합니다.
- 이미지나 영상에 개인정보가 있으면 원본 서비스에서도 공개 범위를 변경하거나 삭제합니다.
- README의 기능 범위가 코드와 달라지면 구현 변경과 함께 문서를 갱신합니다.
